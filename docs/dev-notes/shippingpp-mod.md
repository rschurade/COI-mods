Second CoI mod (separate from ElevationPP): **Shipping++** (id `ShippingPP`, working title, renameable until first release), at `D:\projects\privat\mods\coi\mods\ShippingPP` (since 2026-08-08 a subdir of the `mods` monorepo — see [[git-workflow]]; the old standalone repo at coi\ShippingPP is superseded). Build via `D:\projects\privat\mods\coi\mods\ShippingPP\build.ps1` (mirrors the ElevationPP build; requires COI_ROOT/COI_MODS).

Concept: local cargo terminals (vanilla cargo depot model + modules, vanilla `CargoDepot` entity class, new proto subclass) with ships hauling products dock-to-dock on the same map.

User decisions (2026-08-05):
- Ships are the terminal's **own** (not from the shipwreck pool): "build ship" button, player delivers materials at the terminal; dedicated shipbuilder building maybe later.
- **Automatic matching like the vanilla train network** (offer/request via module direction, thresholds/priorities, two-sided reservations) — not explicit routes.
- New separate building, not a mode on the vanilla depot.
- Keep the fuel mechanic (flat per journey, vanilla-style).

Key vanilla facts: ship = real vehicle (`CargoShipV2 : Ship : PathFindingEntity`), `Ship.NavigateToDock(IDockEntity)` does the full undock→sail→dock chain to any `IDockEntity`; ocean-access check is local (dock trapezoid); ship brain = pluggable `ICargoShipJobProvider` (selection patched in `CargoShipV2.UpdateJobProviderIfNeeded`); corridor clearance: ships need 31×23..61×23 water. Mod state persists via the vanilla manager pattern (public static Serialize/Deserialize; `ShippingManager` has its own SAVE_VERSION stamp, v2 as of 2026-08-05). Ship build cost = 600 ConstructionParts3 (vanilla's ship price at the ships settlement) — user wants it toned down at final polish.
